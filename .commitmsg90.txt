round 90: emergency in-game toggle for the stormbringer proc driver (/raijin proc)

The direct-cast proc driver (ProcForce, 273057 @ 0.3s ICD) proved mechanically
sound in the runtime log (STAGE/DRAIN id=273057 every 0.3s, client accepted each
cast, nrc=1) but the user reported it only produced the cast visual/sound, NOT a
real proc, and there was NO way to stop it in-game — they had to close the game.

Add an in-game, instantly-stoppable toggle so a runaway can never force a client
shutdown again:
  /raijin proc on [icdMs]   enable ProcForce(273057, icdMs default 300)
  /raijin proc off          disable immediately (escape hatch)
  /raijin proc              show state
Implemented as a new ChatHandler 'proc' command branch. Deployed.

Also note (not actioned): direct casting 273057 does NOT trigger the real proc —
it is server-gated (only the cast visual fires). A true 100%/0.3s proc requires
hooking the client's own proc-roll, not replaying the proc's cast spell. That is
the open question for the next step.
