## Dump evidence

```
Last FrameScript_Execute: ... RaijinLab ... type(IsLinuxClient)=...
Time: 10:51:50.751 PM  (matches inject log Register at 22:51:50)
Fatal Condition 0x85100086  (software assert, not AV)
```

## Root cause

Dual-register path called **`0x0084F7A0` as `lua_setfield`**. Disassembly shows that address is **not** lua_setfield — it touches taint globals (`0xD413A0` / `0xD4139C`) and can raise Ascension’s Fatal Condition assert.

`FrameScript_RegisterFunction` is the correct binder (pushcclosure → pushstring → insert → rawset @ LUA_GLOBALSINDEX).

## Fix (runtime 1.4.0-crashfix)

1. **Removed** direct `lua_setfield` / fake setglobal  
2. **Register** only via `FrameScript_RegisterFunction`  
3. **No** `FrameScript_Execute` during bind (toast was the last Execute in dump)  
4. **OM enum off by default** (`om.enable=0`)  
5. Main-thread player GUID via Ping only (TLS-safe)  
6. Optional toast: `register.toast=1` after guid proven  

## Safe inject procedure

   `tools\inject.bat` → uses `RaijinLabRuntime_latest.dll`

5. When stable with guid≠0 in `runtime_status.txt`, optionally set `om.enable=1`
